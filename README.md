# Pure Python Statistics Calculator

A personal learning project built entirely from scratch to deeply understand how statistical algorithms work. 

**Built 100% with Pure Python.** I deliberately avoided using external libraries like `numpy` or `pandas`, and even Python's built-in `statistics` module. Every mathematical formula (Mean, Median, Variance, Standard Deviation, Quartiles, IQR, and Z-Score) has been manually coded to practice algorithmic thinking.

## Key Features
* **Zero Dependencies:** No `pip install` required. Just pure Python logic.
* **Dual Input:** Calculate data by either typing it manually in the terminal or importing a `.csv` file.
* **Interactive Menu:** A crash-resistant CLI (Command Line Interface) built with `match-case`.

## 💻 How to Run
Run the script in your terminal:
